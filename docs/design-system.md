# Design system

- Tokens defined as CSS variables in `app/globals.css`.
- Motion tokens `--ease-out`, `--ease-in-out`, `--ease-drawer`; named-property transitions only.
- Press feedback `scale(0.96)`.
- Reduced motion keeps color/opacity, drops movement.
- Touch targets >= 44px.
- `.scroll-pane` for scrollbars; `.product-row` for content-visibility.
